# 課題：API インターフェース設計書の作成

## 概要

掲示板アプリの API 設計書を OpenAPI 形式（Swagger）で作成してください。
補足：
「Swagger」とは本来、OpenAPI 仕様（API 仕様書のフォーマット）の旧称です。
現在は以下のように役割が分かれています：

Swagger Editor：OpenAPI 仕様の記述を行うツール

Swagger UI：記述された仕様書を閲覧・実行できるツール

ただし、「Swagger」という言葉がまとめて使われることも多いため、文脈によって指すものが異なる点には注意が必要です。

## 前提条件

- 既に定義済みの API
  - ログイン API (`POST /login`)
  - ログインユーザー情報取得 API (`GET /me`)

## 作成方法

`/docs/api/openapi.yaml` を IntelliJ で開き、既に書いてある内容を更新する形で作成してください。

Spring Boot を起動（または swagger-ui コンテナを起動）して http://localhost:8002 へアクセスするとプレビューが表示されます。

## 定義すべき API

以下の機能の API 設計を完成させてください：

### 1. 記事一覧取得

- **機能**: ページネーション・検索機能付きの記事一覧取得
- **認証**: JWT 認証必須
- **検索条件**: タイトル、本文、投稿者名
- **ソート機能**: 作成日時、タイトルでの昇順・降順
- **レスポンス**: 記事サマリー情報の配列とページネーション情報

### 2. 記事登録

- **機能**: 新しい記事の登録
- **認証**: JWT 認証必須
- **入力項目**: タイトル（1-50 文字）、本文（1-10000 文字）
- **レスポンス**: 作成された記事の詳細情報

### 3. 記事詳細取得

- **機能**: 指定された ID の記事詳細とコメント一覧を取得
- **認証**: JWT 認証必須
- **パラメータ**: 記事 ID（パスパラメータ）
- **レスポンス**: 記事詳細情報とコメント配列

### 4. 記事更新

- **機能**: 指定された ID の記事を更新
- **認証**: JWT 認証必須（投稿者のみ）
- **入力項目**: タイトル、本文
- **レスポンス**: 更新された記事の詳細情報

### 5. 記事削除

- **機能**: 指定された ID の記事を削除
- **認証**: JWT 認証必須（投稿者のみ）
- **レスポンス**: 204 No Content

### 6. コメント登録

- **機能**: 指定された記事にコメントを登録
- **認証**: JWT 認証必須
- **入力項目**: コメント内容（1-1000 文字）
- **レスポンス**: 作成されたコメント情報
